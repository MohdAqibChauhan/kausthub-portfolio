# Kaustubh Gondhali — Interactive 3D WebGPU Portfolio

Interactive 3D WebGPU portfolio experience for **Kaustubh Gondhali** (*Graphics Designer | Video Editor | Motion Graphics*).

## 🚀 Quick Start

```bash
node server.cjs
```

- **Main 3D Globe Portfolio:** `http://localhost:3000/`
- **Freehand Drawing Canvas:** `http://localhost:3000/draw`
- **Studio Admin CMS Portal:** `http://localhost:3000/admin` (Default Key: `kaustubh2026`)
